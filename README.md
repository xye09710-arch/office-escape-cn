# 今天必须准时下班 · 第二版

面向中文用户的轻量职场情境网页游戏。下午五点开始，在十八次决策中处理临时任务、群消息、甩锅和下班前的会议，争取把今晚留给自己。

纯静态网页，无账号、无付费接口、无抽卡。界面、事件、结局与成就均为简体中文。办公室人物仅作场景展示，没有地图移动玩法。

## 本地试玩

需要 Node.js 24、npm 11。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。选难度后开始，页面每次决策自动保存；刷新后点击“继续上次”。开始新一局会替换未完成的进度，保留成就。收藏只保存在当前浏览器，清理网站数据会移除存档。

```bash
npm test          # 引擎、剧情、结局、成就、存档测试
npm run test:e2e  # 桌面、手机、窄屏手机的真实浏览器测试
npm run build    # 构建到 dist
npm run preview  # 预览生产构建
npm run check    # 全部验证
```

浏览器测试优先使用系统 `/usr/bin/chromium`。其他系统先运行 `npx playwright install chromium`，或通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定浏览器路径。受限环境可使用 `npm ci --cache /workspace/.npm-cache`。

## 玩法与规则

- 每局恰好十八次决策，四个阶段分别为四、五、五、四题。无倒计时限制，目标阅读与游玩时间约三至五分钟。
- 五项状态为当前时间、工作完成度、老板怀疑值、同事关系、疲劳值。后四项限制在零至一百。
- 共五十七个可达事件，其中五条主线各有四个独立事件、五个隐藏事件、三十二个普通事件；二十个选项需要同事关系达到五十。
- 选项影响状态和路线标记。事件筛选先检查阶段、未出现和前置标记，再由既有选择路径确定下一事件；分支事件权重二、隐藏事件权重三、普通事件权重一。无随机抽取，同一难度与同一路径得到相同剧情和结果。
- 五条路线为边界感、证据链、人情账、摸鱼线、硬扛线。路线可交叉，前面的沟通、帮忙、留证或逃避会解锁后续回响。每局事件不重复。
- 简单难度每题额外增加一点完成度，减少一点怀疑与疲劳；普通使用基础效果；困难每题额外耗时一分钟、怀疑加二、疲劳加一；地狱额外耗时两分钟、完成度少一点、怀疑加三、疲劳加二。怀疑达到六十五后，后续每题另耗两分钟并增加两点疲劳。
- 结算在最后一次选择后进行。完成度不足八十五、怀疑高于四十五、疲劳高于六十五会增加收尾时间。具体计算和取整见 `src/rules.js`。
- 六结局按顺序判断：疲劳至少八十五→工位续费；否则完成度低于七十→尾款是加班；否则怀疑至少六十五→门口被叫回；否则关系至少八十→组队撤离；否则十八点前或整点离开→准点下班；其余→晚了一点。
- 四名同事有独立个性和时间公式，受难度、人情路线、证据路线、摸鱼和工作完成度影响。同分钟并列排名。
- 十四张成就在完整通关后按确定条件解锁，条件直接显示在图鉴中；无概率掉落。稀有度只表示达成难度。
- 战绩按钮复制中文战报；浏览器不允许剪贴板时会显示可手动复制的文本。

## 项目结构

| 文件                           | 用途                         |
| ------------------------------ | ---------------------------- |
| `src/state.js`                 | 初始状态、阶段与时间显示     |
| `src/events.js`                | 中文事件与条件选项           |
| `src/engine.js`                | 事件筛选、选项校验、状态转移 |
| `src/rules.js`                 | 难度、六结局与同事排名       |
| `src/achievements.js`          | 卡牌条件与确定解锁           |
| `src/storage.js`               | 版本化存档、历史重放与收藏   |
| `src/main.js`、`src/style.css` | 界面与像素场景               |
| `tests/`                       | 状态、剧情覆盖与浏览器测试   |

## 部署到 Netlify

新建站点并连接本仓库，构建命令 `npm run build`，发布目录 `dist`，Node.js 版本为 24。仓库已有 `netlify.toml`，也可在本地构建后将 `dist` 上传到一个新站点。无需服务端或环境密钥。

本任务不自动创建或覆盖 Netlify 站点。正式上线建议使用 HTTPS，以支持剪贴板功能。

## 验证范围

单元测试以固定种子的策略模拟覆盖全部五十七个事件、六种结局与十四张卡牌，并检查条件触发、四阶段边界、存档续玩及重复结算。种子仅用于测试生成选择序列，游戏运行本身不使用随机数决定事件或解锁。

浏览器测试在一四四〇像素桌面、三九〇像素手机、三二〇像素窄屏手机上完整通关，验证四档难度、十八题阶段、刷新续玩、收藏持久化、排名、分享与横向溢出。测试使用 Chromium 的触屏模拟，未宣称真机或所有浏览器兼容性。
